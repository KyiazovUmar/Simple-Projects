# Simple Python & Web Projects

A lightweight collection of interactive mini-projects featuring a digital whiteboard web app, a password strength auditor CLI tool, and a Matrix terminal digital rain animation.


* **Digital Whiteboard (`index.html`)**
  * Interactive web application built with Tailwind CSS and HTML, JS
  * Features pan/zoom canvas controls, freehand pen drawing, custom sticky notes, and moveable text elements.

* **Password Auditor (`password_auditor.py`)**
  * Python command-line utility to evaluate password security.
  * Checks length, character variety (uppercase, lowercase, numbers, special symbols), and common security patterns.

* **Terminal Matrix Rain (`terminal_matrix.py`)**
  * Python script generating the classic Green Matrix "digital rain" effect inside your command line interface.
  * Dynamically adapts to your terminal window size using system color codes.
